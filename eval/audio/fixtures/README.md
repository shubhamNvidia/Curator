# Fixtures & E2E runbook

Self-contained fixtures for the agent test harness (see `../AGENT_TEST_PLAN.md`).

## Contents

- `manifests/*.jsonl` — small manifests exercising the shapes the agent must handle:
  - `tiny_with_transcripts.jsonl` / `tiny_no_transcripts.jsonl` — the opt-in E2E smoke inputs.
  - `multi_speaker.jsonl` — diarization shape (speaker counts).
  - `longform.jsonl` — long-form / segmentation shape.
  - `bad_sample_rate.jsonl` — 8 kHz rows to trip `card_sample_rate` when data profiling is on.
- `audio/` — generated by `make_fixtures.py` (not committed).
- `novel_stage/` — a brand-new stage + card the agent never saw during development
  (test-plan **level 14**), plus `novel_card_check.py` which proves the discovery
  and conformance machinery generalize to it with no core change.

## Generate the tiny audio (for the opt-in E2E smoke)

`make_fixtures.py` writes short mono 16 kHz sine WAVs with the Python stdlib (no
numpy/soundfile), then rewrites the two tiny manifests with absolute paths:

```bash
python eval/audio/fixtures/make_fixtures.py
```

## Run the opt-in E2E smoke

The `execute` cases in `queries.yaml` are skipped by default. Enable them (needs a
reachable Ray + the venv):

```bash
python eval/audio/fixtures/make_fixtures.py
AUDIO_AGENT_EVAL_EXECUTE=1 python -m eval.audio.run_eval --report eval/audio/reports/latest_e2e.json
```

The bundled smoke uses only `GetAudioDurationStage` (no models), so it runs on the
synthetic clips. For real model stages (ASR/quality/diarization), point a manifest
at real audio (e.g. FLEURS clips under `/tmp/aa_real`) and reuse the deep-test Ray
head on `:6457` / the RTX 4090.

## Level-14 generalization proof

```bash
python eval/audio/fixtures/novel_stage/novel_card_check.py   # -> PASS
```

Importing the fixture stage registers it via the stage metaclass; the card gate
(`card_conformance.check_card`) then re-derives its contract and validates the new
card with zero drift — the same path shipped stages use.
